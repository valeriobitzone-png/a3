# A3UI 0.2 — catalogo minimo chiuso
## Scopo
Chiudere il LANGUAGE GAP di P56 (b): A3UI 0.1 ha tempo/moto/gesti, non contenuto.
Tre tipi. Ogni *Spec extra è GAP. Renderer resta 0.1: (b)→(a) è esprimibilità del payload, non pixel nuovi.
## I 3 tipi
### Node — ruolo, non widget
```
Node { id, role, children[] }
role ∈ {stack, row, list, item, action, field, text}
```
Gerarchia = figli. `row > [text, action]` è il layout. Niente LayoutSpec.
Catalogo chiuso: `grid` / `modal` / `tooltip` → schema reject.
### Binding — atom.k → node.id (lista sulla surface, non dentro Node)
```
Binding { atomKey, nodeId, role: content | placeholder | value }
```
`atomKey` = `PresentationAtom.k` (o Fact.k) già sul `PresentationState` passato al compile.
Il valore dell'atomo è la copy. Niente i18n, niente formatter.
Atomo assente → nodo vuoto. Non throw, non copy inventata. `placeholder` non è testo di fallback: è solo il ruolo del binding.
### GestureBinding — 0.1 + target (lista sulla surface)
```
GestureBinding { gesture, targetNodeId, action }
```
`targetNodeId` deve esistere nel tree (compile throw se no).
`action` ∈ nomi semantici già usati (`confirm`, `dismiss`, `select`, `next-step`).
Node NON duplica bindings/gestures. Un solo puntatore per tipo.
## Prefetch
Estendere `PrefetchSpec` 0.1 con `atomKeys: List<String>` opzionale.
Niente `prefetchSurface: A3UISurface` (sarebbe una seconda surface, quarto concetto).
Niente PrefetchContentSpec.
## Compile (solo :a3ui)
Port 0.1: `compile(projection: Projection): A3UISurface` non vede gli atomi.
0.2: `compile(projection: Projection, presentation: PresentationState): A3UISurface`
`PresentationState` è il tipo frozen in `a3.projection.model`. Non si modifica `:projection`.
`compilePrefetch` già ha `candidate.presentation`.
## Fuori scope
| Apparente | Dove vive |
|---|---|
| Validation | Planner / Goal.constraints |
| Payment | Trust irreversible |
| Pixel / Compose / View | `renderers/` frozen |
| Step machine | tree di Node + action `next-step` (tutti i passi presenti; non è uno state machine) |
| Input type | Binding `role=value` + tipo nel BeliefState |
## A3UI-0.2-INV
Node = ruolo. Binding = atom.k → node.id. Gesture ha target. Gerarchia = figli.
Lo scenario treno di P56 è esprimibile con questi tre. Se serve altro: LANGUAGE GAP documentato, non workaround nel renderer.
## Migrazione da 0.1 (campi REALI sul disco)
`A3UISurface` 0.1 ha: id, projectionRef, presentationRef, lineage, densityHint, colorTokens, motion, morph, gestures, haptics, prefetch, producedAt.
Non esiste `temporal-components`. Non esiste `HapticSpec` (è `HapticMap`).
0.2 aggiunge `nodes[]`, `bindings[]`; `gestures` diventa lista di GestureBinding con `targetNodeId`; `PrefetchSpec.atomKeys` opzionale.
`MotionSpec` / `MorphSpec` / `HapticMap` immutati.
## Schema
`a3uisurface.schema.json` v0.2. Non backward compatible.
